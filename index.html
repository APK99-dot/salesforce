Privacy Policy

Singhania Drive Connector is a private integration used only by its owner. It connects the owner's Salesforce org to the owner's own Google Drive so that files can be stored in and read from a single Drive folder.

The app accesses only the files it creates or the folder the owner chooses. It does not sell, share or transfer any Google user data to third parties, and it does not use the data for advertising.

Access can be removed at any time from the Google Account under Security → Third-party access.

Contact: via the support email shown on the Google consent screen.
